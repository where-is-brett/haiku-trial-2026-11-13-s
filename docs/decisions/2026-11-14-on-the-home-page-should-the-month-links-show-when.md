# On the home page, should the month links show when only statement-import is on, or only when month-page is on as well?

- **Date:** 14 November 2026
- **Piece:** statement-import
- **Options:** A. Show the month list only when both statement-import and month-page are on, so no link is dead (The months stay hidden until the month page is also on; Can be undone) · B. Show the month list when statement-import is on, and leave month-page to be switched on with it (Visible links that return Not found until the month page is switched on; Can be undone)
- **Recommended:** both
- **Chosen:** both
- **The director's words:** none
